# Gameplay Genre And Mode Catalog

This catalog intentionally includes strong fits, uncertain ideas, weak fits,
and moonshots. It is a memory and combination surface, not a ranked backlog.

## Catalog Keys

| Fit | Meaning |
|---|---|
| Promising | Skiing materially changes the genre and a credible experiment exists. |
| Uncertain | The fantasy is interesting but a central rule or feel question is unresolved. |
| Weak | Preserved despite population, differentiation, or movement conflicts. |
| Moonshot | Potentially defining, but effectively a new production phase. |

`Donor` may be appended to any fit when the row is primarily preserved as a
mechanic for other modes rather than a likely standalone mode.

Relative cost starts from the current authoritative multiplayer/CTF baseline:
`S`, `M`, `L`, and `XL`.

## Racing, Routes, Style, And Player Authorship

| Direction | Fit / cost | Core loop | Low-pop form | Main unknown or reusable idea |
|---|---|---|---|---|
| Point-to-point racing | Promising / S-M | Cross a landscape using the best line. | Excellent ghosts and records. | Early mistakes in long races. |
| Circuit racing | Promising / S-M | Race repeated laps with energy and recovery decisions. | Ghost laps. | Collision policy and first-corner chaos. |
| Rally / stages | Promising / S-M | Run staggered technical stages for cumulative time. | Ideal solo and asynchronous play. | Less direct multiplayer interaction. |
| Combat racing | Uncertain / M | Race while discs disrupt recoverable lines. | Targets and hazards. | Randomness and runaway leaders. |
| Linecraft | Promising / M | Discover, validate, share, and challenge player-defined ski lines. | Excellent solo and asynchronous play. | Route validation, discovery, and moderation. |
| HORSE | Promising / M | One player sets a route or feat and others reproduce it. | Excellent at 2-4 players. | Fairly describing and validating complex attempts. |
| Trackmania-style editor | Promising / L | Publish courses, medal times, ghosts, and leaderboards. | Excellent solo. | Editor, storage, moderation, and discovery scope. |
| Trick Line | Promising / M | Chain jumps, spins, near-misses, and clean landings. | Solo score chase. | First-person trick readability. |
| Score Attack | Promising / S-M | Optimize targets, pickups, speed, and combo value in one arena. | Excellent solo. | Arbitrary scoring and exploit dominance. |
| Traversal puzzles | Promising / M | Solve constrained energy, speed, route, and landing problems. | Excellent solo/co-op. | Precision accessibility and reset friction. |

Open Lines, Linecraft, and player-set challenges are intentionally separate
forms of one authorship family: Open Lines activates ephemeral authored routes,
Linecraft persists player-defined lines, and commons challenges issue a route
socially without requiring persistent publication.

## Hybrids Worth Remembering

| Combination | Smallest useful interpretation |
|---|---|
| Contested Core + CTF | Central target fight releases the only flag; destination is home or enemy goal. |
| Contested Core + Breakline | Released Core activates branching route thresholds before scoring. |
| Contested Core + Ricochet | Carry the Core or launch it through passes and goals. |
| Open CTF + Lounge | Players join teams through portals and leave active play without disconnecting. |
| Open Lines + Linecraft | A validated player route becomes the next voluntary server challenge. |
| Foxhunt + bounty banking | The runner gains value while surviving but must expose a route to bank it. |
| Relay Grid + Courier | Every delivery establishes or strengthens a strategic route link. |
| Vector Lock + Flyby CTF | A carrier must qualify directional gates before completing a capture. |
| Wake Run + escort | A payload moves at ski speed and scores continuity in its wake. |
| Harvester + Push | Combat pickups move a shared front when deposited. |
| Heist + extraction delivery | A brief breach starts a long open-terrain getaway. |
| Storm + rally | Staggered racers choose lines while a forgiving hazard closes routes. |
| Rescue + cooperative traversal | Players must reach shared checkpoints and recover one another. |
| Dynamic terrain + route setting | Temporary server-owned blockers alter lines without deformable terrain. |
| Commons + rotating events | One shared basin hosts short optional modes without requiring a playlist queue. |

## Shared Map Vocabulary

An early compact competitive basin can expose paired goals, a central objective
socket, directional gates, control sockets, target plates, and a moving-objective
path. A longer open terrain can expose branching routes, delivery nodes,
landmarks, shelters, and a commons loop.

Reusable authoritative objective primitives include:

- Carried object, neutral projectile, pickup, deposit, and extraction zone.
- Directional gate, control node, target plate, and destructible module.
- Moving emitter, timed hazard, route graph, and temporary blocker.
- Elapsed time, possession, delivery, capture, route link, bounty, survival,
  combo, and stage-time scoring.

The catalog should grow by adding concepts and combinations, not by deleting
ideas that fall out of immediate favor.

and four parallel design passes covering Tribes base play, modern objective
modes, original SKOOSH mode pitches, and competitive-playtest scope. A later
genre survey and research-framework pass expanded the set. Those transient
discussions are not repository artifacts, so the table below is the durable
source inventory. Future additions should name their date and source in the
relevant row or commit. This checklist prevents cleanup from silently erasing a
seed merely because its current fit is weak.
